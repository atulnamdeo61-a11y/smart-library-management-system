Smart Library Management System

College Computer Science / IT Minor Project Specification & Overview

1. Project Abstract & Objectives

The Smart Library Management System is an end-to-end full-stack web application designed to digitize and automate college library circulation. It replaces manual paperwork with a centralized relational database, role-based authorization, dynamic inventory stock tracking, and smart features including QR code shelf tagging and personalized book recommendations.

2. 5-Layer Modular Architecture

Presentation Layer

HTML5, CSS3 Variables, Bootstrap 5, Jinja2 template inheritance, Chart.js visualizations.

Application Layer

Flask Application Factory, Blueprints (Auth, Books, Student, Admin, Librarian), Flask-WTF CSRF protection.

Service Layer

Decoupled business logic: CirculationService, FineService, QRService, RecommendationService, AnalyticsService.

Data Access Layer

SQLAlchemy ORM models with explicit foreign keys, indexes, unique constraints, and atomic transactions.

Database Engine

MySQL 8.0 relational database with normalized schema, audit trails, and migration support.

3. Role-Based Permissions Matrix

Operation Administrator Librarian Student
Search & Browse Books, Scan QR
Submit Borrow Request
Personalized Recommendations
Approve Requests & Issue Books
Process Book Returns & Record Fines
Add / Edit / Safe Delete Books
Waive Fines & Change System Rules
Manage Staff Accounts & Audit Logs

4. Smart Algorithms

Personalized Recommendation Engine: Operates directly on the relational database without expensive external paid APIs. Weights student explicit category preferences (5 pts), borrowing history category frequency (2.5 pts/loan), deprioritizes already read books, and incorporates overall college borrow popularity.

Indian Rupee Fine Accrual: Employs date-only interval calculation with configurable grace period (default 0 days) and standard rate (₹2.00 per day), preventing charges prior to due date or after return date.
